Dimensions vs. file size — they're not the same thing

Two different "sizes" often get muddled. Dimensions are how many pixels wide and tall the image is (e.g. 1920×1080). File size is how many megabytes it takes up. They're related — fewer pixels usually means a smaller file — but they're controlled separately. If a form rejects your photo for being "too large," it might mean either one, so it helps to know which lever you're pulling. Resizing the dimensions is usually the most powerful way to cut file size.

How to avoid stretching and distortion

A picture distorts when you change its width and height to a different shape than the original — squashing a wide photo into a square, for instance. The fix is the aspect ratio lock: keep it on and the image scales proportionally, so nothing stretches. If you genuinely need a different shape (say a square thumbnail from a landscape photo), crop it to that shape first, then resize — that trims the picture instead of warping it.

Common sizes for social media and the web

Handy targets to type straight into the resizer:

  • Instagram square — 1080 × 1080
  • Instagram portrait — 1080 × 1350
  • Story / Reel — 1080 × 1920
  • YouTube thumbnail — 1280 × 720
  • Profile picture — 400 × 400 (square)

For a square avatar, crop to a 1:1 shape first so faces stay centred, then resize down.

Making an image bigger — what to expect

Enlarging is different from shrinking. Shrinking throws away pixels and looks clean. Enlarging has to stretch the pixels you already have, which can come out soft or blocky. An upscaler does this more intelligently and can sharpen the result — but be realistic: it reconstructs detail from what's in the file, it doesn't invent genuinely new detail that was never captured. For best quality, start from the largest original you have.

Frequently asked questions

How do I resize to exact pixel dimensions?

Type the width and height you want in the resizer and download. Lock the ratio to scale proportionally; unlock it to force an exact, possibly stretched, size.

Will resizing distort my photo?

Only if you change it to a different shape. Keep the aspect ratio locked, or crop to the target shape first.

Does enlarging add detail?

No — it stretches existing pixels. An upscaler can sharpen the result but can't recover detail that was never there.

Are my images uploaded?

No. Resizing happens entirely in your browser; your images never leave your device.
